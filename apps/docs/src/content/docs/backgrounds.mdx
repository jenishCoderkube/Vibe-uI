# WebGL Background Shaders

High-performance, GPU-accelerated WebGL background shaders built with OGL and React for modern landing pages.

Vibe UI includes **5 GPU-accelerated WebGL background shaders** built on top of OGL. Unlike video backgrounds or heavy Three.js scenes, these shaders run at **60fps with less than 25KB runtime footprint**, providing ambient lighting and depth for hero sections and modal backdrops.

You can interactively customize every parameter (colors, flow speed, density, glow, waviness) inside the live [Vibe Studio](/studio).

---

## Quick CLI Installation

```bash
npx vibe-ui-kit add [shader-name]
```

---

## Shader Collection

- **[Light Tunnel](/docs/backgrounds/light-tunnel)** — 3D perspective warp tunnel with glowing cable pulses and interactive flow direction.
- **[Lightfall](/docs/backgrounds/lightfall)** — Ambient vertical falling light beams with customizable density, twinkling stars, and background glow.
- **[Web Threads](/docs/backgrounds/web-threads)** — Geometric intersecting thread lines with harmonic sine wave oscillations.
- **[Sliced Waves](/docs/backgrounds/sliced-waves)** — Parametric horizontal and vertical segmented wave grid with ripple falloff.
- **[Scanner](/docs/backgrounds/scanner)** — Cyberpunk laser sweep radar with high-frequency scanlines and chromatic distortion.
