# Next.js Installation & Setup

Integrate **Vibe UI** components into a Next.js 15 App Router application with Tailwind CSS.

<Callout type="warning" title="Important Notice">
  Do <strong>not</strong> run <code>npm install vibe-ui</code>. Vibe UI is distributed via our official CLI: <strong><code>npx vibe-ui-kit</code></strong>.
</Callout>

<Steps>

<Step title="1. Create a Next.js Project">

Create a new Next.js application using `create-next-app` with TypeScript, Tailwind CSS, and the `@/*` alias:

```bash
npx create-next-app@latest my-vibe-app --typescript --tailwind --app --src-dir --import-alias "@/*"
cd my-vibe-app
```

</Step>

<Step title="2. Initialize Vibe UI via CLI">

Run the `vibe-ui-kit` CLI initializer inside your project directory:

```bash
npx vibe-ui-kit@latest init -y
```

*What this step does:*
- Detects Next.js and your `src/` folder structure.
- Creates `src/lib/utils.ts` with the `cn()` class merge utility.
- Automatically writes Vibe UI design tokens and glassmorphism styles directly into `src/app/globals.css`.
- Installs required peer packages (`clsx`, `tailwind-merge`, `tailwind-variants`, `@radix-ui/react-slot`, `lucide-react`).

</Step>

<Step title="3. Add Components to Your Project">

Add any component from the 94 available items directly to your project:

```bash
npx vibe-ui-kit@latest add button card
```

The component files are created in `src/components/ui/` (e.g. `button.tsx` and `card.tsx`), giving you full code ownership.

</Step>

<Step title="4. Import & Use in Your Application">

Open `src/app/page.tsx` and use the components with any of the built-in theme presets:

```tsx
import { Button } from "@/components/ui/button"
import {
  Card,
  CardHeader,
  CardTitle,
  CardDescription,
  CardContent,
} from "@/components/ui/card"

export default function Home() {
  return (
    <main className="flex min-h-screen items-center justify-center p-6 bg-background">
      <Card className="w-[380px]">
        <CardHeader>
          <CardTitle>Welcome to Vibe UI</CardTitle>
          <CardDescription>
            Next.js 15 + Tailwind CSS + Multi-Aesthetic Themes
          </CardDescription>
        </CardHeader>
        <CardContent className="flex flex-col gap-3 pt-2">
          <Button variant="default">Default Variant</Button>
          <Button variant="glass">Glassmorphic Variant</Button>
          <Button variant="glow">Neon Glow Variant</Button>
          <Button variant="retro">Retro Card Variant</Button>
          <Button variant="cyberpunk">Cyberpunk Variant</Button>
        </CardContent>
      </Card>
    </main>
  )
}
```

Start your dev server to see it in action:

```bash
npm run dev
```

</Step>
