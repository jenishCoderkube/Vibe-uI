# Manual Setup Guide

If you prefer not to use the CLI, you can manually configure **Vibe UI** into any React project in 4 simple steps.

<Callout type="warning" title="Important Notice">
  Do <strong>not</strong> run <code>npm install vibe-ui</code>. The <code>vibe-ui</code> package on npm is an unrelated package. Follow the manual setup steps below.
</Callout>

<Steps>

<Step title="1. Install Core Dependencies">

Install the required class merge utilities, variant composers, and UI primitives:

```bash
npm install clsx tailwind-merge tailwind-variants lucide-react @radix-ui/react-slot
```

If you plan to use Motion text effects or WebGL background shaders, also install:

```bash
npm install motion ogl
```

</Step>

<Step title="2. Create the Utility Helper File">

Create a file at `src/lib/utils.ts` (or `src/lib/utils.js` for JavaScript) and add the `cn()` helper:

```typescript
import { clsx, type ClassValue } from 'clsx'
import { twMerge } from 'tailwind-merge'

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}
```

Make sure your project's `tsconfig.json` has the `@/*` alias mapped to `./src/*`:

```json
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

</Step>

</Step>

<Step title="4. Copy Desired Components into Your Codebase">

Create a `src/components/ui/` directory.

You can copy component code directly from the **Code** tab on any component page on the [Vibe UI Documentation](https://vibe-ui-kit.vercel.app/), or fetch raw JSON from the registry at:
```
https://vibe-ui-kit.vercel.app/registry/components/[component-name].json
```

For instance, create `src/components/ui/button.tsx` and paste the Button component source.

</Step>

<Step title="5. Import and Use">

```tsx
import { Button } from '@/components/ui/button'

export default function App() {
  return (
    <div className="flex gap-4 p-8">
      <Button variant="default">Default</Button>
      <Button variant="glass">Glass</Button>
      <Button variant="glow">Glow</Button>
      <Button variant="retro">Retro</Button>
      <Button variant="cyberpunk">Cyberpunk</Button>
    </div>
  )
}
```

</Step>

</Steps>
