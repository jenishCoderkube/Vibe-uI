## Block Concept

Vibe UI's Kanban 01 block provides a complete agile team workspace layout. It includes 4 distinct workflow columns (Backlog, In Progress, In Review, Done) with responsive horizontal scroll and column switcher, task creation modal dialog, subtask progress tracker, interactive comment drawer, and sprint velocity analytics.
