# Introduction

Welcome to the **Vibe UI** component library. This is a production-ready, beautifully designed React component library built for Tailwind CSS v4 and React 19.

## Features

- **Tailwind CSS v4**: Built on the new CSS-first Tailwind compiler.
- **React 19 & Next.js 15**: Leverages modern React server and client capabilities.
- **Multi-Preset Themes**: Built-in Default, Glassmorphism, Retro Neobrutalism, and Neon Glow visual styles.
- **Copy-Paste & CLI Workflow**: Add components directly into your project using `npx vibe-ui-kit add`.
- **Accessible & Responsive**: Fully accessible UI primitives optimized for all screen sizes.
