# Text & Motion Animations Directory

Vibe UI features a powerful suite of **20+ text animations and motion effects** that bring your landing pages, headers, and UI interactions to life. Built using performant CSS `@keyframes` and `motion` (Framer Motion), each effect is fully responsive and GPU-accelerated.

---

## ⚡ Quick CLI Installation

Install any animation component directly into your project:

```bash
npx vibe-ui-kit add [animation-name]
```
