# Installation & Setup

Get started with **Vibe UI** in your React or Next.js project. Vibe UI is a copy-and-paste component collection built with Tailwind CSS, Radix UI, and Motion.

<Callout type="warning" title="Important Notice">
  Do <strong>not</strong> run <code>npm install vibe-ui</code>. The <code>vibe-ui</code> package on npm is an unrelated third-party library. Always install and manage components using our official CLI: <strong><code>npx vibe-ui-kit</code></strong>.
</Callout>

---

## ⚡ The 3-Step Quick Start

If you already have a project with Tailwind CSS installed, getting started takes under a minute:

<Steps>

<Step title="1. Initialize Vibe UI in Your Project">

Run the CLI initializer in your project root:

```bash
npx vibe-ui-kit@latest init
```

*What this does automatically:*
- Detects TypeScript or JavaScript and maps your folder structure (e.g. `src/`).
- Creates `@/lib/utils.ts` with the standard `cn()` class merging utility.
- Injects Vibe UI design tokens (HSL variables, glassmorphic utilities) into your global CSS (`globals.css` or `index.css`).
- Installs base peer dependencies (`clsx`, `tailwind-merge`, `tailwind-variants`, `@radix-ui/react-slot`, `lucide-react`).

<Callout type="tip" title="Non-Interactive Fast Setup">
  To skip all interactive prompts and accept recommended defaults automatically, pass <code>--yes</code>:
  <br />
  <code>npx vibe-ui-kit@latest init -y</code>
</Callout>

</Step>

<Step title="2. Add the Components You Need">

Add components directly into your codebase with automatic dependency resolution:

```bash
npx vibe-ui-kit@latest add button card dialog
```

*What this does:*
- Downloads the component code directly into `@/components/ui/` (e.g. `src/components/ui/button.tsx`).
- Automatically resolves and installs any required Radix UI primitives or helper packages.
- Leaves you with **100% code ownership** — no vendor lock-in, fully editable.

</Step>

<Step title="3. Import & Enjoy Multi-Theme Variants">

Import the components anywhere in your application:

```tsx
import { Button } from "@/components/ui/button"

export default function Demo() {
  return (
    <div className="flex flex-wrap gap-4 p-6">
      <Button variant="default">Standard</Button>
      <Button variant="glass">Glassmorphism</Button>
      <Button variant="glow">Neon Glow</Button>
      <Button variant="retro">Retro Card</Button>
      <Button variant="cyberpunk">Cyberpunk</Button>
    </div>
  )
}
```

</Step>

</Steps>

## 🛠️ CLI Command Reference

The `vibe-ui-kit` CLI comes with powerful developer tools:

```bash
# Add specific components
npx vibe-ui-kit add button card sheet

# Launch interactive component picker
npx vibe-ui-kit add

# Install all 94 components and application blocks at once
npx vibe-ui-kit add --all

# List all available components from your terminal
npx vibe-ui-kit list

# Inspect a component and its dependencies before adding
npx vibe-ui-kit info chat-01

# Check for differences between local components and upstream registry
npx vibe-ui-kit diff button

# Run diagnostics on Tailwind, CSS directives, and peer dependencies
npx vibe-ui-kit doctor

# Upgrade installed components to latest upstream versions
npx vibe-ui-kit update --all
```
