# Marquee

A premium, high-performance infinite auto-scroll component built to display seamless scrolling logos, system alerts, dynamic testimonial cards, or tech stack badges.

<Installation name="marquee">

{`"use client"

import * as React from "react"
import { cn } from "@/lib/utils"

export interface MarqueeProps extends React.HTMLAttributes<HTMLDivElement> {
  className?: string
  reverse?: boolean
  pauseOnHover?: boolean
  direction?: 'left' | 'right' | 'up' | 'down'
  speed?: number
  fade?: boolean
  gap?: string
  repeat?: number
}

const Marquee = React.forwardRef<HTMLDivElement, MarqueeProps>(
  (
    {
      className,
      reverse = false,
      pauseOnHover = false,
      direction = "left",
      speed = 30,
      fade = true,
      gap = "1rem",
      repeat = 4,
      children,
      ...props
    },
    ref
  ) => {
    const isVertical = direction === "up" || direction === "down"
    const marqueeStyles = {
      "--gap": gap,
      "--duration": \`\${speed}s\`,
    } as React.CSSProperties

    return (
      <div
        ref={ref}
        style={marqueeStyles}
        className={cn(
          "group relative flex overflow-hidden p-2 select-none",
          isVertical ? "flex-col" : "flex-row",
          className
        )}
        {...props}
      >
        {Array.from({ length: repeat }).map((_, i) => (
          <div
            key={i}
            className={cn(
              "flex shrink-0 justify-around [gap:var(--gap)]",
              isVertical
                ? "flex-col animate-marquee-vertical"
                : "flex-row animate-marquee",
              direction === "right" && "animate-marquee-reverse",
              direction === "down" && "animate-marquee-vertical-reverse",
              reverse && "[animation-direction:reverse]",
              pauseOnHover && "group-hover:[animation-play-state:paused]"
            )}
          >
            {children}
          </div>
        ))}

        {fade && (
          <>
            <div
              className={cn(
                "pointer-events-none absolute z-10",
                isVertical
                  ? "inset-x-0 top-0 h-12 bg-gradient-to-b from-background to-transparent"
                  : "inset-y-0 left-0 w-12 bg-gradient-to-r from-background to-transparent"
              )}
            />
            <div
              className={cn(
                "pointer-events-none absolute z-10",
                isVertical
                  ? "inset-x-0 bottom-0 h-12 bg-gradient-to-t from-background to-transparent"
                  : "inset-y-0 right-0 w-12 bg-gradient-to-l from-background to-transparent"
              )}
            />
          </>
        )}
      </div>
    )
  }
)

Marquee.displayName = "Marquee"

export { Marquee }
`}

</Installation>



## Tailwind Configuration (v4)

Ensure you add the marquee custom variables and `@keyframes` into your theme file (e.g., `globals.css` or `tokens.css`):

```css
@theme {
  --animate-marquee: marquee var(--duration, 30s) linear infinite;
  --animate-marquee-reverse: marquee-reverse var(--duration, 30s) linear infinite;
  --animate-marquee-vertical: marquee-vertical var(--duration, 30s) linear infinite;
  --animate-marquee-vertical-reverse: marquee-vertical-reverse var(--duration, 30s) linear infinite;

  @keyframes marquee {
    from { transform: translateX(0); }
    to { transform: translateX(calc(-100% - var(--gap, 1rem))); }
  }
  @keyframes marquee-reverse {
    from { transform: translateX(calc(-100% - var(--gap, 1rem))); }
    to { transform: translateX(0); }
  }
  @keyframes marquee-vertical {
    from { transform: translateY(0); }
    to { transform: translateY(calc(-100% - var(--gap, 1rem))); }
  }
  @keyframes marquee-vertical-reverse {
    from { transform: translateY(calc(-100% - var(--gap, 1rem))); }
    to { transform: translateY(0); }
  }
}
```

## Component Concept

Vibe UI's Marquee component provides a high-performance, CSS-animation-powered scrolling container that duplicates children seamlessly. It is ideal for showcasing brand logos, code feeds, matrix blocks, or any list of items that needs to slide continuously.

### Key Attributes & Options

- **`reverse`**: `boolean` (default `false`) — Reverse the animation direction.
- **`pauseOnHover`**: `boolean` (default `false`) — Pause scroller motion when mouse hovers over it.
- **`direction`**: `'left' | 'right' | 'up' | 'down'` (default `'left'`) — Set axis and alignment direction.
- **`speed`**: `number` (default `30`) — Animation cycle duration in seconds (smaller is faster).
- **`fade`**: `boolean` (default `true`) — Show smooth overlay fade gradients on scroller edges.
- **`gap`**: `string` (default `'1rem'`) — Margin spacing gap between consecutive scrolling items.
- **`repeat`**: `number` (default `4`) — Number of duplicated sets of children to fill view seamlessly.
