# React Components Directory

Welcome to the complete **Vibe UI React Components** directory. Every component is designed to be copied directly into your project using the [Vibe UI CLI](/docs/cli), giving you 100% ownership and zero runtime lock-in.

All components support **Light & Dark mode**, **Tailwind CSS v4**, **React 19**, and include full **WAI-ARIA keyboard navigation and accessibility**.

---

## ⚡ Quick Installation

Add any component instantly with our official CLI:

```bash
npx vibe-ui-kit add [component-name]
```

Or run the interactive picker to select multiple components at once:

```bash
npx vibe-ui-kit add
```

## 🔘 Buttons & Actions

Core interactive controls for triggers, buttons, and segmented actions.

- **[Button](/docs/components/button)** — The foundational action element with 7 variants: `default`, `secondary`, `outline`, `ghost`, `destructive`, `glow`, and `retro`.
- **[Button Group](/docs/components/button-group)** — Connected segmented button containers for toolbars and toggle groups.
- **[Toggle](/docs/components/toggle)** — Two-state icon or text button for switching options on and off.
- **[Kbd](/docs/components/kbd)** — Stylized keyboard shortcut indicators for commands and accessibility tips.
